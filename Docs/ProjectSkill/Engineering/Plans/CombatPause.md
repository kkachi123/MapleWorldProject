# CombatPause — 전투 일시정지 후속 확인 계획

## 목표·상태

2026-10-18 사용자 승인으로 현재 맵 AI 자동 확인과 분리한 실제 맵 전환·화면·음향을 확인한다. 아래 두 항목은 미실시다. 현재 동작은 [CombatPause 개발문서](../Features/0_CombatPause.md)를 따른다.

승인 없는 추가 맵·콘텐츠·배포·수치 변경은 하지 않는다. 실패 시 영향 범위와 필요한 수정부터 정리한다.

## 후속 확인

| ID | 주체·상태 | 실행 조건·통과 기준 |
| --- | --- | --- |
| CombatPause-F01 | AI·본인 / 미실시 | 4단계 실제 두 번째 맵·전환 흐름 마련 후 공격·복귀·가드/회피·팝업 승인 대기/표시 중 전환. 이전 예약·정지·입력·UI·시간 배율 정리와 새 맵 재연결, 오래된 응답 무시 확인. 훅 직접 호출로 대체하지 않음 |
| CombatPause-F02 | 본인 직접 평가 / 대기 | PC·모바일 가로 화면에서 모션·이펙트·숫자 정지, 팝업·토스트·BGM/효과음 지속, 닫기·홀드 해제·중앙 복귀·버튼/실제 터치 확인. 특히 몬스터 die 가시성·전체 재생 여부 확인. 로그만으로 화면·음향 통과 금지 |

F01은 기존 CombatPause-V07, F02는 V05/V06/V08의 미확인 환경이다. [CombatFoundation-F03/F04](CombatFoundation.md) 및 [이동 V08](../Features/1_MovementInput.md)은 2026-10-20 사용자 확인 완료다. 이 완료 보고는 F01/F02의 별도 관찰 근거가 아니므로 두 항목은 미실시로 유지한다. 기존 Maker Stop·사망 확인을 실제 맵 전환이나 기기 검증으로 확대하지 않는다.

## 진행·종료

실행 재개 시 AI 상세 작업은 Engineering/WorkRecords/CombatPauseWorkRecord.md에 임시 기록하고 본인 피드백과 구분한다. 확인한 현재 결과만 Features에 짧게 반영한다. 두 항목이 처리되고 결과·링크 정리가 끝나면 계획과 임시 작업 기록을 삭제한다. 미실시는 남긴다.
