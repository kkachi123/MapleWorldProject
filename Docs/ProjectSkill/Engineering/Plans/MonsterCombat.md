# MonsterCombat — 점프 데이터화·판정 시인성 검토 계획

## 제작 의도·상태

본인은 직접 플레이에서 주황버섯 점프가 빠르다고 보고하고, 이후 몬스터 제작 시 조절을 검토하도록 요청했다. 2026-10-18 검토 초안·미구현이며 현재 수치를 변경하는 승인이 아니다. [로드맵 6단계](../DevelopmentRoadmap.md)를 따른다.

## 착수 시 참고할 기존 설정·주의사항

2026-10-18 AI 진단 요약이며 현재 소스를 새로 검증한 결과가 아니다.

- [OrangeMushroomAttack](../../../../RootDesk/MyDesk/Monster/OrangeMushroom/OrangeMushroomAttack.mlua): JumpDuration=0.5초·JumpHeight=0.8. 접근/복귀 공통 시간이며 먼 지점일수록 수평 이동이 빠르게 보인다.
- [MonsterData.csv](../../../../RootDesk/MyDesk/@Assist/DataSet/MonsterData.csv)는 id/name/modelid만 연결한다. 점프 열만 추가해도 적용되지 않는다.
- 공격은 착지 시 1회, 박스 크기 (1,1)·오프셋 (0,0.4)·기본 피해 12. 착지 높이는 Home 기준이다. 지속 공격·다른 높이의 지형 지원을 전제하지 않는다.
- 과거 MonsterCombat-V01은 설정 소유자, V02~V05는 이른 대기 시 피해 12, V06은 저스트 회피 피해 0·자동 반격 2, V07은 판정 후 진입 시 추가 판정 없음 확인이다.
- 각 조건 1회·즉시 이동 버전의 AI Maker 확인이다. 현재 걷기 패턴 전체의 재검증이나 사용자가 겪은 상황의 원인 확정이 아니다. 당시 종료 프로브 해제 오류 2건도 있어 전체 무오류로 표현하지 않는다.
- 최신 이동·일시정지 동작은 [1단계](../Features/1_MovementInput.md)·[0단계](../Features/0_CombatPause.md)를 참조한다. 완료된 진단의 상세 원장·별도 영구 개발문서는 유지하지 않는다.

## 본인이 결정할 사항

- 먼/가까운 지점에 같은 시간으로 도착할지, 일정 속도로 이동할지의 원하는 체감.
- 접근·복귀 시간과 점프 높이를 각각 조절할 필요가 있는지.
- 공격 예고·착지 시점·회피 성공 표시의 개선 요구. 지속 공격 추가는 별도 승인 대상.

현재 조절 방식·열 이름·기본값·누락 정책은 AI 설계안 검토 후 확정한다. 선택 이유는 본인 답변이 있을 때만 기록한다.

## AI 구현 범위·단계

- MonsterCombat-P01: 실제 착수 시 결정사항·범위 확정. 현재 미착수.
- P02: 승인 범위에서 데이터·서버 로더·모션 적용·기본값/잘못된 값 처리 설계. CSV 열만 추가해 끝내지 않음.
- P03: 제작 승인 후 구현. 실제 이동 완료와 판정 시점 일치, 취소·사망·종료 경계 유지.
- P04: 자동 회귀와 본인 직접 점프 체감 평가 후 결과 정리.

## 확인 기준

- AI: 설정 변경이 접근·복귀·높이에 반영되고 누락/잘못된 값이 정한 정책으로 처리됨.
- AI: 가까운/먼 지점·세 위치의 이동과 판정 시점 일치. 중단·사망·종료 후 늦은 피해/IDLE 없음.
- AI: 이동 속도만 조절할 때 기존 피해·타격·회피 규칙을 변경하지 않음. 이른 대기/직전 회피/판정 후 진입 구분.
- 본인: 실제 플레이에서 점프 체감 평가. 표시 개선을 승인한 경우 예고·판정·회피 성공을 구분할 수 있는지도 확인.
- 느려졌다는 이유만으로 가독성 전체를 완료 처리하지 않음.

착수 후 상세 작업은 Engineering/WorkRecords/MonsterCombatWorkRecord.md에 임시로 남긴다. 완료 후 Features에는 설정·현재 결과·본인 평가·역할만 반영하고, 계획·임시 기록은 필요한 정보와 링크 정리 후 삭제한다.
