# Project StayCool — 작업 요청 양식

## 첫 연결

새 메인 채팅에 다음처럼 요청한다.

```text
Docs/ProjectSkill/ChatRoles/README.md와 .claude/skills/ship/SKILL.md를 읽어줘.
현재 프로젝트의 Plan·Feature·WorkRecord를 확인하고 네 담당의 역할과 실제 위임 도구 사용 가능 여부를 보고해줘.
지금은 문서 확인만 하고 구현·Maker 실행·다른 채팅 메시지 전송은 하지 마.
```

Claude Code에서는 /ship {요청}으로 부른다. 스킬 목록에 ship이 보이지 않으면 위 양식처럼 SKILL.md 경로를 명시하고, 필요하면 세션을 다시 시작한다. 역할 계약 원본은 공용 .agents/skills/ship/references이고, 네 담당은 .claude/agents의 msw-* 에이전트로 실행한다.

## 작업 인계에 넣을 항목

```text
작업: {만들거나 고칠 결과}
모드: {계획 / 승인 범위 구현·검증 / 검증 / 재검토 / 상태 조회}
기준 문서: {실제 Plan·Feature·WorkRecord 경로}
승인 범위: {이번에 허용하는 구현·테스트}
유지/제외: {바꾸지 않을 정책·수치·기능}
확인 기준: {관찰할 결과, 사용자 직접 확인할 부분}
사용 환경: {Maker 사용 가능 여부·현재 담당·기기}
질문이 필요한 조건: {미확정 규칙·범위 확대 등}
```

이 항목을 단순 조회에도 전부 강제하지 않는다. 없는 자료·승인·도구는 있는 것처럼 채우지 않는다. .pipeline의 run-id는 실행 시작 시 정하고 재개 시 같은 ID를 지정한다.

## 상태만 확인

```text
현재 로드맵 단계와 대상 Plan을 기준으로 진행 상태를 확인해줘.
구현·QA·리뷰·사용자 확인을 구분하고, 남은 검증 ID와 다음 담당을 보고해줘.
실행·수정·메시지 전달 없이 조회만 해줘.
```

## 새 기능 계획

```text
{제작 목표}를 현재 MSW 기획과 연결해 Plan으로 정리해줘.
이번에는 planner만 사용하고 구현·Maker 실행은 하지 마.
사용자가 결정할 규칙과 AI의 기술 제안을 구분해줘.
```

## 승인 계획 구현·검증

```text
/ship {승인된 Plan 경로}의 {요구/작업 ID}를 구현·검증해줘.
msw-planner, msw-coder, msw-tester, msw-reviewer 에이전트에 순차 위임해줘.
기존 확정 규칙은 유지하고, 새 규칙이나 다음 로드맵 단계는 진행하지 마.
Maker는 이전 담당 사용이 끝났는지 확인하고 coder/tester가 순차 사용해줘.
필수 사용자 직접 확인이나 환경 부재는 대기로 보고해줘.
```

/ship이 인식되지 않으면 첫 줄을 다음처럼 바꾸고 나머지 범위를 유지한다.

```text
.claude/skills/ship/SKILL.md를 읽고 {승인된 Plan 경로}의 {요구/작업 ID}를 구현·검증해줘.
```

실제 위임을 실행하지 못했다면 독립된 네 담당이 수행했다고 보고하지 않는다. 스킬 사용 자체가 미승인 구현·다음 단계 실행을 허용하지 않는다.

## 기존 결함 수정·재검증

```text
{run-id}의 {결함 ID}만 수정하고 관련 조건을 다시 검사해줘.
기준은 {Plan 경로·요구 ID}이며 무관한 조작·수치·UI는 바꾸지 마.
요구가 그대로라면 coder → tester → reviewer로 진행하고,
새 기획 결정이 필요하면 planner 확인과 사용자 판단에서 멈춰줘.
```

## 검토만 요청

```text
{대상 Plan}과 {변경 버전·WorkRecord}를 reviewer에게 검토시켜줘.
제품·기획·QA 판정은 바꾸지 말고, 근거 부족·요구 누락·범위 밖 변경을 보고해줘.
실행 검사가 더 필요하면 직접 성공을 추정하지 말고 필요한 조건을 남겨줘.
```

역할별 입력·기록·반환 형식은 [역할 참조](../../../.claude/skills/ship/SKILL.md)의 정의, 실행 순서는 ship, 상태 양식은 [.pipeline](../../../.pipeline/README.md)을 따른다.
